# Images du carrousel de connexion

Dépose ici jusqu'à 5 photos (classe, campus, élèves, événements...) nommées :

```
slide-1.jpg
slide-2.jpg
slide-3.jpg
slide-4.jpg
slide-5.jpg
```

Format recommandé : paysage, au moins 1600x1000px, JPG compressé (<500 Ko/image)
pour un chargement rapide. Tant qu'aucune image n'est présente, la page de
connexion affiche simplement le dégradé de couleur (voile encre bleu) sans
photo derrière — aucun crash, juste un fond uni le temps que tu ajoutes tes
visuels.

La liste des fichiers utilisés se configure dans
`src/features/auth/LoginPage.tsx` (constante `CAROUSEL_IMAGES`).
